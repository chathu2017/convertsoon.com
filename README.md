# ConvertSoon 🚀
**An AI-Powered Document Conversion Tool**

Welcome to the official open-source repository for [ConvertSoon.com](https://convertsoon.com)! 

## 🌟 About The Project
ConvertSoon is a 100% free document conversion tool. I completely self-funded and built this project from scratch to give back to the tech community. While the live website helps everyday users convert files easily using AI, this **source code** is shared here for a different reason: **Community Education**.

As a Microsoft Certified Trainer (MCT) and Cloud Architect, I strongly believe in practical learning. I regularly use this live architecture as a real-world case study during my free weekend training sessions. By exploring this repository, junior engineers and students can learn exactly how a true **Azure Hybrid Architecture** works in a real production environment.

## 🛠️ Tech Stack & Hybrid Architecture
Instead of a standard cloud setup, this project demonstrates a highly cost-optimized hybrid approach:
* **Backend Framework:** Python (FastAPI) served via **Nginx**
* **Hybrid Cloud Base:** Third-party VM seamlessly integrated with Azure using **Azure Arc**
* **Cloud Security:** Secured by **Microsoft Defender for Servers** (enabled via Arc)
* **Traffic Routing:** **Azure Traffic Manager** to optimize user access
* **AI Engine:** OpenAI API

## 💡 Why Open Source?
I want to help newcomers not just read about cloud technology, but actually see how it is built. Showing you the actual hybrid architecture I designed gives a much better hands-on learning experience than just talking about theory. My goal is to give you the confidence to start building your own cost-effective cloud and AI projects. Feel free to explore the code, learn from the structure, and use it to grow your skills!
